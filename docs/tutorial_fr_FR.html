Prise en main rapide

Du logiciel vide au premier modèle entraîné, le chemin le plus court tient en ces six étapes. Les détails de chaque étape sont donnés dans les chapitres suivants.

  1. Ajouter un projet — cliquez sur « + Ajouter un projet » à gauche, saisissez un nom.
  2. Ajouter un jeu de données — clic droit sur le nœud de projet → « Ajouter un jeu de données ».
  3. Importer des données — sélectionnez le jeu de données, cliquez sur « Importer » en haut, puis choisissez le dossier des images et celui des étiquettes.
  4. Vérifier les données — cliquez sur « Propriétés », vérifiez que les classes et les quantités sont correctes.
  5. Entraîner — cliquez sur « Entraîner », choisissez le type de tâche et le jeu de données, laissez le reste par défaut, puis cliquez sur « Démarrer l'entraînement ».
  6. Voir le résultat — une fois l'entraînement terminé, retrouvez cet enregistrement dans « Modèles » et cliquez sur « Tester » pour lancer une passe sur le jeu de validation ; pour livrer, exportez un rapport PDF.
Si vous n'avez pas encore de données annotées, commencez par le chapitre 3 « Annotations ».

1. Interface et projets

1.1 Disposition de l'interface principale

L'interface principale se compose de trois zones : à gauche la gestion des projets, au centre l'affichage des images, la barre d'outils en haut.

  • Arborescence des projets à gauche — projets et jeux de données sont organisés de façon hiérarchique. Après le jeu de données vient la progression des annotations (par ex. 126/128) ; le point devant le nom indique s'il est chargé en mémoire : vert = chargé, rouge = non chargé.
  • Zone d'images au centre — navigation par pages dans les vignettes. En bas au centre, un groupe de commandes de pagination : deux flèches encadrent le numéro de page, le numéro de la page courante est mis en évidence ; en survolant le numéro de page, vous voyez le nombre total d'images selon le filtre actif.
  • Barre d'outils en haut — échelle d'affichage, liste déroulante de filtrage des annotations, ainsi que les boutons Modifier, Supprimer, Importer, Exporter, Propriétés, Entraîner, Modèles, Journal, etc.

1.2 Projets et jeux de données

Ajouter un projet : cliquez sur « + Ajouter un projet » à gauche, saisissez un nom, validez. Un projet est le conteneur des jeux de données ; chaque jeu de données doit appartenir à un projet.

Clic droit sur un nœud de projet :

  • Ajouter un jeu de données — crée un nouveau jeu de données dans le projet
  • Exporter le projet — exporte les jeux de données et les annotations de tout le projet dans le format choisi
  • Renommer — renomme le projet
  • Supprimer le projet — supprime aussi les jeux de données, les annotations et les enregistrements d'entraînement qu'il contient

Le clic droit sur un nœud de jeu de données agit sur un seul jeu de données : Importer / Exporter / Déplacer / Renommer / Supprimer.

Un double-clic sur le jeu de données est nécessaire pour le charger : il rescanne les images et les annotations, reconstruit le cache, et vous pouvez ensuite parcourir la partie droite. Si le jeu de données a déjà été chargé (point d'état sur la ligne), un nouveau double-clic ne relance pas le scan.

1.3 Importer des données

Sélectionnez le jeu de données, cliquez sur « Importer » en haut : la boîte de dialogue d'import s'ouvre :

  • Chemin des images — le dossier qui contient les images
  • Chemin des étiquettes — le dossier qui contient les fichiers d'annotations
  • Format des étiquettes — Yolo txt / Labelme json / Importer comme classification (sous-dossiers)
Jeu de données de classification : choisissez « Importer comme classification (sous-dossiers) » ; chaque nom de sous-dossier correspond à une classe, aucun fichier d'annotation n'est nécessaire.
L'OCR utilise Labelme json ; l'étiquette des zones de texte est fixée à « text » et, après l'import, le jeu de données est automatiquement marqué comme jeu de données de détection de texte.

1.4 Propriétés du jeu de données

Sélectionnez le jeu de données et cliquez sur « Propriétés » en haut : vous voyez le chemin des images, le chemin des étiquettes et un histogramme de répartition des étiquettes — combien de zones annotées compte chaque classe. On repère d'un coup d'œil la classe qui manque d'échantillons.

1.5 Langue de l'interface

À l'extrême droite de la barre d'outils se trouve la liste déroulante de la langue de l'interface, avec neuf langues au choix : 中文、English、繁體中文、日本語、한국어、Deutsch、Español、Français、Tiếng Việt.

Dès que vous la sélectionnez, l'interface principale change immédiatement, et les fenêtres Journal et File d'attente d'entraînement déjà ouvertes sont actualisées en même temps ; les boîtes de dialogue pas encore ouvertes s'afficheront dans la nouvelle langue à la prochaine ouverture. Le choix est mémorisé : au prochain démarrage, la langue reste la même. Chaque entrée de la liste est libellée dans sa propre langue, donc quelle que soit la langue de l'interface, vous savez quelle entrée choisir.

2. Annotations

2.1 Accéder à l'interface d'annotation

Après avoir sélectionné le jeu de données, faites un clic droit sur une vignette et choisissez « Annotations », ou double-cliquez directement sur la vignette.

2.2 Dessiner des zones

La barre d'outils en haut de l'interface d'annotation propose trois modes de tracé :

  • Rectangle — faites glisser la souris pour tracer une zone
  • Polygone — cliquez les sommets l'un après l'autre, terminez par un double-clic ou Entrée (pour les tâches de segmentation)
  • Texte — activez d'abord l'interrupteur « Annotation de texte » en haut, puis tracez une zone ; au relâchement, une boîte de saisie s'ouvre pour enregistrer le texte, un double-clic permet de le modifier (pour les tâches OCR)

Pour dessiner une zone de texte, utilisez toujours le Rectangle. Pour du texte incliné, une zone horizontale suffit — à l'entraînement, un polygone est traité comme sa boîte englobante horizontale : suivre le contour n'apporte rien de plus.

La barre d'outils contient aussi « Supprimer l'image », qui supprime l'image courante.

Les classes se choisissent dans la liste d'étiquettes à droite.

L'interrupteur « Afficher les annotations » masque à tout moment tous les contours (traits de zone, étiquettes, poignées de sommets) pour mieux voir l'image d'origine. Pour un élément déjà collé mais pas encore validé, seuls les contours sont masqués et le motif reste visible : le désactiver est donc idéal pour prévisualiser « le rendu une fois collé ».

En bas à droite, « Annotations » liste, pour chaque objet annoté de l'image, sa forme (Rectangle / Polygone), son nombre de sommets et son aire ; juste en dessous, Infos image affiche la largeur × hauteur × nombre de canaux de l'image courante (par ex. 505×505×3) ainsi que son numéro.

Encore en dessous se trouve le Presse-papiers : après avoir copié un polygone par clic droit, une vignette de la zone copiée (120 × 90) vient s'y ajouter, jusqu'à 9 au maximum, empilées verticalement et défilables. La plus récente est sélectionnée par défaut et bordée de bleu ; un clic droit sur une vignette permet de la supprimer ou de tout vider.

2.3 Gestion des étiquettes

À droite de l'interface d'annotation se trouve la liste d'étiquettes, avec en haut « Ajouter une étiquette » :

  • Nom de l'étiquette — plusieurs étiquettes séparées par des virgules : vous pouvez en ajouter plusieurs d'un coup
  • Importer — reprendre en bloc les étiquettes d'un autre jeu de données
  • Couleur — choisissez dans la palette prédéfinie, ou cliquez sur « Couleur personnalisée » pour la définir vous-même

2.4 Modifier les classes

Modifier une seule zone : cliquez sur une zone annotée, un menu déroulant de classes s'ouvre, il suffit de choisir la nouvelle classe. Les étiquettes de la liste à droite peuvent aussi être renommées, recolorées ou supprimées.

Modification en lot : clic droit sur une vignette → « Modifier les classes en lot », indiquez la classe d'origine et la nouvelle classe ; toutes les annotations de cette classe dans le jeu de données sont renommées.

2.5 Copier et coller des objets annotés

Un clic droit sur une annotation Polygone propose deux actions :

  • Copier — enregistre les pixels de cette zone comme modèle et crée une vignette dans le presse-papiers en bas à droite
  • Remplir — remplace les pixels de la zone par la couleur RVB correspondant aux trois champs « Valeur de remplissage » (par canal 0 ~ 255, 255 par défaut). Sert souvent à effacer un défaut avec la couleur du fond

Cliquez avec le bouton gauche sur une vignette du presse-papiers, puis déplacez le curseur sur le canevas : un contour de polygone en pointillés vous suit — la forme est le contour réel après rotation, avec l'angle tiré au sort pour cette fois déjà appliqué. Repérez bien le point de pose et l'orientation, appuyez sur Esc pour masquer les pointillés et revenir au mode souris normal, puis faites un clic droit et choisissez « Coller » pour valider.

Faites un clic droit sur une zone vide de l'image et choisissez « Coller » : la vignette actuellement sélectionnée dans le presse-papiers est collée à la position du curseur, dans la même image ou dans une autre. Avant de coller, réglez ces quelques éléments dans la barre d'outils :

  • Plage d'angles — intervalle d'angles de rotation aléatoire appliqué au collage (-180 ~ 180 par défaut). L'aperçu en pointillés utilise précisément l'angle tiré dans cet intervalle : ce que vous voyez est ce que vous obtenez
  • Intensité de fusion — 0 ~ 1, 0.70 par défaut. Au collage, la luminosité est compensée et les bords adoucis automatiquement, pour que la partie collée se fonde naturellement dans le fond ; à 0, le collage est brut
  • Valeur de remplissage — trois champs R / G / B (par canal 0 ~ 255, 255 par défaut), à utiliser avec « Remplir » du menu contextuel pour effacer la zone avec cette couleur
  • Ctrl + Z — annule le dernier collage ou remplissage : les pixels sont restaurés et les annotations ajoutées dans la foulée sont supprimées en même temps ; vous pouvez annuler plusieurs fois de suite

2.6 Réglage de la luminosité d'une zone polygonale

Sélectionnez un Polygone et activez Luminosité dans « Paramètres » de la barre d'outils pour éclaircir ou assombrir les pixels à l'intérieur de ce polygone. Faites glisser le curseur ou saisissez directement une valeur : l'aperçu est en temps réel sur l'image.

  • Plage — 0 ~ 1 ; la valeur par défaut 0.50 laisse l'image d'origine. Plus vous allez vers 1, plus c'est clair (1.00 correspond à peu près au double de la luminosité), plus vous allez vers 0, plus c'est sombre (0 = tout noir)
  • Ne s'applique qu'au polygone sélectionné. Avec un rectangle, ou quand rien n'est sélectionné, seul un message s'affiche et les pixels ne changent pas. Cliquez sur un autre polygone : le curseur revient à sa propre valeur (0.50 pour ceux qui n'ont jamais été réglés) sans reprendre la luminosité du précédent
  • Quand l'écriture sur disque a lieu — pendant le glissement, seuls la mémoire et l'aperçu en temps réel sont modifiés. Le fichier image n'est écrit qu'en changeant d'image avec A / D ou en appuyant sur Ctrl + S
  • Annuler — chaque réglage ne compte que pour une seule étape ; Ctrl + Z revient à l'état d'avant le réglage. Faire des allers-retours sur le curseur au cours d'un même réglage ne compte toujours que comme une étape

2.7 Filtrer les images par classe

Dans la liste déroulante des classes de la barre d'outils en haut, sélectionnez une classe : la zone d'images n'affiche plus que les images contenant cette classe. Pratique pour vérifier ou compléter les annotations d'une classe en particulier.

3. Entraînement

3.1 Configurer les paramètres d'entraînement

Cliquez sur « Entraîner » depuis la page d'accueil ou l'interface des modèles : la configuration des paramètres s'ouvre :

  • Type de tâche — Détection / Segmentation / Classification / Détection d'anomalies / OCR ; il bascule automatiquement selon le format du jeu de données
  • Jeu d'entraînement / Jeu de validation — sélection multiple possible, et combinaison entre projets
  • Appareil — liste automatiquement les GPU disponibles
  • Époques / Optimiseur / Arrêt anticipé — l'optimiseur est adamw pour la détection et la segmentation, sgd pour la classification ; l'arrêt anticipé interrompt l'entraînement après N époques consécutives sans amélioration, la valeur 0 le désactive
  • Taux d'apprentissage — décroît automatiquement pendant l'entraînement
  • Lot / Taille d'image / Accumulation de gradient / Threads — la taille d'image doit être un multiple de 32 ; si la VRAM est insuffisante, réduisez le lot et augmentez l'accumulation de gradient, ce qui revient à agrandir le lot
  • Chemin de sortie — laissé vide, un dossier est généré automatiquement à partir de l'horodatage ; vous pouvez aussi cliquer sur « Parcourir » pour le spécifier

3.2 File d'attente d'entraînement

Une fois les paramètres définis, en plus de « Démarrer l'entraînement », vous pouvez cliquer sur « Ajouter à la file d'attente » pour mettre la tâche en attente et enchaîner la configuration de la suivante. Depuis la page d'accueil, cliquez sur « File d'attente d'entraînement » pour ouvrir la fenêtre de la file :

  • La file s'exécute dans l'ordre ; Détection / Segmentation / Classification / Détection d'anomalies / OCR peuvent être mélangés, et une fois une tâche terminée, la suivante démarre automatiquement
  • Monter / Descendre / Retirer — réorganiser l'ordre d'exécution ou supprimer une tâche
  • Modifier — modifier les paramètres de la tâche sélectionnée
  • Nettoyer les tâches terminées — retirer les enregistrements déjà exécutés
  • Démarrer la file d'attente — exécuter les tâches de la file l'une après l'autre depuis le début
La file d'attente convient au travail de nuit : configurez d'un coup les tâches de plusieurs jeux de données, le logiciel les exécutera toutes automatiquement et enregistrera un modèle pour chacune.

3.3 Progression de l'entraînement

Après avoir cliqué sur « Démarrer l'entraînement » et être revenu à la page d'accueil, une barre de progression et une barre de contrôle apparaissent en haut :

  • Nom de la tâche + progression — de la forme coco128 entraînement 5/100 ; la barre de progression indique le loss de l'époque en cours
  • Arrêter l'entraînement — interrompt à tout moment ; la partie déjà exécutée est conservée
  • Temps restant — estimé par extrapolation à partir du temps déjà écoulé
  • VRAM — taux d'occupation de la mémoire du GPU, actualisé en temps réel

3.4 Courbes d'entraînement

Dans le gestionnaire de modèles, sélectionnez un enregistrement d'entraînement et cliquez sur « Voir toutes les métriques » dans le panneau de détails à droite : la fenêtre des courbes d'entraînement s'ouvre :

  • La partie supérieure affiche la courbe val loss
  • La partie inférieure regroupe plusieurs courbes : mAP@50-95 / mAP@50 / AR / F1 / precision / recall, etc. ; pour la segmentation, une courbe mask mAP s'y ajoute
  • En haut à droite, la liste déroulante « Filtre d'étiquettes » permet de basculer entre toutes les métriques et les courbes d'une classe donnée

4. Gestionnaire de modèles

Cliquez sur « Modèles » depuis la page d'accueil pour ouvrir le gestionnaire de modèles : à gauche la liste des enregistrements d'entraînement, à droite le panneau de détails.

4.1 Liste et filtres

  • Champ de recherche — filtre par mot-clé sur le projet / le jeu de données / l'étiquette
  • Listes Tâche / État — pour la tâche : Détection / Segmentation / Classification / Détection d'anomalies / Détection de texte / Reconnaissance de texte ; pour l'état : Entraînement / Terminé / Échec / Arrêté
  • Meilleur par jeu de données uniquement — ne conserve que l'entrée la plus précise pour chaque jeu de données
  • Colonnes de la liste : Tâche, Jeu de données · Étiquette, Précision, Date d'entraînement, Durée, Taille d'image, Actions
  • La colonne Précision comporte une barre de couleur — vert ≥ 0.8, jaune 0.5 ~ 0.8, rouge < 0.5. Pour les enregistrements en échec ou arrêtés, cette colonne affiche le texte d'état ; en laissant le curseur dessus, vous voyez la cause de l'échec
  • Trois boutons sur la ligne : Tester (ouvre le test du modèle), Exporter, Supprimer (supprime aussi l'enregistrement d'entraînement correspondant)

4.2 Panneau de détails

Cliquez sur n'importe quelle ligne : le panneau de droite affiche tous les paramètres de cet enregistrement — Tâche · Échelle, État, Précision, Jeu d'entraînement / Jeu de validation, Taille d'image, Époques / Arrêt anticipé, Taille de lot, Taux d'apprentissage, Optimiseur, Appareil, Étiquette, Date d'entraînement, Durée, Chemin du modèle. En haut figure aussi une vignette de la courbe de précision.

Quatre boutons en bas du panneau :

  • Voir toutes les métriques — ouvre la fenêtre des courbes d'entraînement (voir la section « Courbes d'entraînement »)
  • Tester ce modèle — ouvre la boîte de dialogue de test avec ce modèle (voir la section « Paramètres de test »)
  • Réentraîner avec cette configuration — reprend tous les paramètres d'entraînement de cet enregistrement et relance un entraînement
  • Ouvrir le dossier du modèle — localise le fichier de poids dans l'explorateur de fichiers

4.3 Exporter en ONNX

Cliquez sur « Exporter » et choisissez un dossier : un dossier « 项目_时间戳 » est généré :

  • Modèle .onnx — la détection et la segmentation sont exportées par RF-DETR, la classification et l'OCR par torch. Le nom est « 项目_任务_图像尺寸_模型规模.onnx »
  • classes.txt — correspondance entre les id de classe et les noms. Pour le segment de reconnaissance d'OCR, c'est vocab.txt : un caractère par ligne, c'est le vocabulaire
  • Rapport d'évaluation PDF — lance automatiquement une évaluation sur le jeu de validation, réutilise le modèle du rapport de test et nomme le fichier « …_评估报告.pdf »
  • examples/ — exemples de code C++ / C# / Python appelant l'ONNX pour la détection, la segmentation et la classification. L'OCR n'a pour l'instant qu'une version Python

L'export affiche une progression. La conversion ONNX exige l'installation de onnx et onnxsim ; sinon, une boîte de dialogue vous le signale.

Les tâches de classification ne génèrent pas de rapport d'évaluation — le rapport d'oublis et de fausses détections ne s'applique pas à la classification. Il en va de même pour la reconnaissance de texte de l'OCR, dont la seule conclusion est le CER.

5. Test et rapport d'évaluation

5.1 Paramètres de test

Dans le gestionnaire de modèles, cliquez sur « Tester » sur la ligne (ou sur « Tester ce modèle » dans le panneau de détails) : la boîte de dialogue de test s'ouvre. En haut s'affichent les informations du modèle : Type de tâche, Fichier de poids, Précision d'entraînement, Taille d'entrée, Échelle. En dessous, les paramètres :

  • Données — tous les jeux de données, tous projets confondus, sont sélectionnables
  • Appareil — par défaut, le premier GPU disponible
  • Confiance — les prédictions en dessous de ce score sont écartées directement
  • Seuil IoU — une détection n'est comptée correcte que si le recouvrement entre la zone prédite et la zone annotée atteint le seuil
  • Écrire les fichiers d'étiquettes — coché, les zones prédites sont écrites en labelme json, pour faciliter la vérification manuelle
  • OCR — la détection de texte propose deux voies, inférence et évaluation : l'inférence écrit les résultats en json d'annotation, l'évaluation calcule P/R. La reconnaissance de texte ne produit pas de fichier d'annotation, elle rapporte seulement le taux de reconnaissance des extraits de texte
Quand le jeu de données est annoté, le logiciel passe automatiquement en mode d'évaluation et calcule le taux de détection / les oublis / les fausses détections. Pour la détection de texte, si le mode inférence est choisi, les annotations sont ignorées et les zones prédites sont écrites directement en json.

5.2 Analyse des résultats

Une fois le test terminé, la fenêtre d'analyse des résultats s'ouvre ; les statistiques se font selon deux axes et les termes employés sont toujours les très explicites « Détections correctes / Oublis / Fausses détections » :

  • Dimension image (statistiques par image ; une seule détection suffit pour compter l'image comme détectée) — Images testées, Images détectées et taux de détection, Images non détectées, Images avec fausses détections
  • Dimension annotation (statistiques par zone annotée) — Détections correctes, Oublis, Fausses détections, Précision
  • Tableau par classe — pour chaque classe : nombre d'annotations, détections correctes, oublis, fausses détections, taux de détection, précision
  • Reconnaissance de texte — pas de statistiques par zone : indique le nombre total d'extraits de texte, le CER (taux d'erreur de caractères) et le nombre d'extraits entièrement corrects
  • Conclusion en bas — une phrase indique si l'ensemble penche vers les oublis ou vers les fausses détections, ainsi que la classe qui pèse le plus

5.3 Exporter le rapport PDF

Cliquez sur « Exporter le rapport PDF » en bas à droite : il est généré par un thread en arrière-plan et contient :

  • Page de synthèse — tableau récapitulatif des métriques + graphique de répartition des annotations
  • Page des échantillons oublis / Page des échantillons fausses détections — présente des vignettes selon « N images par classe » (le nombre se règle en bas à gauche), les oublis et les fausses détections sont encadrés en rouge sur les images, avec la proportion d'échantillonnage indiquée
  • Page de recommandations — propose des pistes d'amélioration pour chaque type d'erreur
L'échantillonnage n'intervient qu'à l'étape de génération du rapport ; les données détaillées restent complètes, donc l'exploration des cas difficiles ne perdra aucune donnée.

6. OCR

L'OCR diffère des autres tâches : il est réalisé par deux modèles enchaînés — la détection de texte localise les zones de texte, la reconnaissance de texte lit les caractères dans ces zones. L'entraînement, le test et l'export se font en deux segments séparés, et deux enregistrements apparaissent dans le gestionnaire de modèles.

6.1 Annoter du texte

Dans l'interface d'annotation, activez l'interrupteur « Annotation de texte » en haut : la classe est automatiquement fixée à l'étiquette réservée « text » (pas besoin de créer l'étiquette au préalable). Encadrez le texte comme pour un rectangle ; au relâchement de la souris, une boîte de saisie s'ouvre pour enregistrer le contenu ; un double-clic sur une zone de texte existante permet de la modifier à tout moment.

Les zones de texte se dessinent toujours avec le rectangle : pour du texte incliné, une zone horizontale suffit ; à l'entraînement, un polygone est traité comme sa boîte englobante horizontale, donc suivre le contour n'apporte rien de plus.

À l'import, un labelme json contenant des zones de texte marque automatiquement le jeu de données comme jeu de données de détection de texte. Ensuite, seuls ces jeux de données apparaissent dans la liste déroulante du jeu d'entraînement OCR.

Une fois l'annotation terminée, revenez à la vue du jeu de données : dans un jeu de données OCR, chaque zone de texte est découpée en une vignette distincte, et la barre d'étiquette affiche le contenu textuel saisi dans la zone (au-delà de 3 éléments, repliés en +N), et non le nom de la classe — parcourir les vignettes une à une permet de vérifier que le contenu saisi est correct. Dans le filtre de classes en haut, il n'y a que l'entrée « text ».

6.2 Entraînement

Choisissez OCR comme type de tâche.

La taille d'image est l'entrée du segment de détection (1024 par défaut, doit être un multiple de 32) ; le segment de reconnaissance est fixé à 32×128 et n'est pas concerné par ce réglage.

Après avoir cliqué sur « Démarrer l'entraînement », le travail est automatiquement scindé en deux tâches mises en file : d'abord la détection de texte, puis la reconnaissance de texte. Une fois la première terminée, la suivante ne démarre qu'après le retour de la VRAM à son niveau d'avant l'entraînement ; pendant ce temps, la zone de progression affiche « Attente de la libération de la VRAM · suivant : Reconnaissance de texte », sans temps mort.

Le vocabulaire du segment de reconnaissance reprend directement les caractères apparus dans les annotations. Le texte annoté doit donc couvrir le jeu de caractères réellement rencontré sur le terrain — un caractère présent sur site mais absent des annotations ne sera pas reconnu par le modèle.

6.3 Test : deux voies pour la détection, une pour la reconnaissance

  • Détection de texte · Inférence — ne compare pas les annotations et écrit directement les zones prédites (avec le texte reconnu) en labelme json. Le json produit porte un marqueur OCR et, une fois glissé dans le logiciel, il est reconnu comme jeu de données de détection de texte, ce qui permet de vérifier les résultats ou de compléter les annotations
  • Détection de texte · Évaluation — activée automatiquement quand le jeu de données est annoté ; calcule les détections correctes / oublis / fausses détections et les P/R par classe, comme pour la tâche de détection
  • Reconnaissance de texte — se teste sur les extraits de texte découpés à partir des zones annotées ; indique le nombre total d'extraits, le CER (taux d'erreur de caractères) et le nombre d'extraits entièrement corrects, sans produire de fichier d'annotation

6.4 Export

Les deux segments exportent chacun un ONNX : 项目_字符检测_尺寸_规模.onnx et 项目_字符识别_尺寸_规模.onnx ; le segment de reconnaissance inclut en plus un vocabulaire vocab.txt.

La détection de texte génère un rapport d'évaluation comme d'habitude ; la reconnaissance de texte n'a que le CER comme conclusion et ne génère pas de rapport.

Un exemple d'appel se trouve dans examples/python/ocr.py du dossier d'export. Attention : les logits produits par le segment de détection ne passent pas par une sigmoïde, le post-traitement est à écrire soi-même ; tout est déjà écrit dans l'exemple.

7. Journal

Cliquez sur « Journal » en haut de la page d'accueil : la fenêtre du journal s'ouvre et défile en temps réel :

  • Démarrage / fermeture du logiciel
  • Création, renommage, suppression, import / export de projets et de jeux de données
  • Création, renommage, suppression d'étiquettes
  • Démarrage, déroulement de l'entraînement (sortie du sous-processus relayée avec le préfixe [train]), mise à jour des métriques, sauvegarde du modèle, arrêt manuel
  • Lancement, déroulement (préfixe [test]), achèvement, échec du test
