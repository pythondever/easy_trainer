빠른 시작

빈 화면에서 첫 모델을 만들어 내기까지 가장 짧은 경로는 이 여섯 단계입니다. 각 단계의 자세한 내용은 뒤의 각 장에서 다룹니다.

  1. 프로젝트 추가 — 왼쪽의 「+ 프로젝트 추가」를 클릭하고 이름을 입력합니다.
  2. 데이터셋 추가 — 프로젝트 노드를 마우스 오른쪽 버튼으로 클릭 → 「데이터셋 추가」.
  3. 데이터 가져오기 — 데이터셋을 선택하고 상단의 「가져오기」를 클릭한 뒤, 이미지 폴더와 라벨 폴더를 각각 선택합니다.
  4. 데이터 확인 — 「속성」을 클릭해 클래스와 수량이 잘못되지 않았는지 확인합니다.
  5. 학습 — 「학습」을 클릭하고 작업 유형과 데이터셋을 선택한 뒤, 나머지는 기본값으로 두고 「학습 시작」을 클릭합니다.
  6. 결과 확인 — 학습이 끝나면 「모델」에서 해당 기록을 찾아 「테스트」를 클릭해 검증 세트에서 한 번 돌려봅니다. 납품이 필요하면 PDF 보고서를 한 부 내보냅니다.
아직 어노테이션 데이터가 없다면 먼저 3장 「어노테이션」을 보세요.

1. 인터페이스와 프로젝트

1.1 메인 화면 구성

메인 화면은 세 부분으로 나뉩니다. 왼쪽은 프로젝트 관리, 가운데는 이미지 보기, 도구 모음은 위쪽에 있습니다.

  • 왼쪽 프로젝트 트리 — 프로젝트와 데이터셋이 계층 구조로 나열됩니다. 데이터셋 뒤에는 어노테이션 진행률(예: 126/128)이 표시됩니다. 이름 앞의 점은 메모리 로드 여부를 나타내며, 초록색은 로드됨, 빨간색은 로드되지 않음입니다.
  • 가운데 이미지 영역 — 썸네일을 페이지 단위로 넘겨 봅니다. 하단 중앙에 페이지 넘김 컨트롤이 있습니다. 두 화살표 사이에 페이지 번호가 있고, 현재 페이지 숫자는 강조 표시됩니다. 페이지 번호 위에 마우스를 올리면 현재 필터 기준으로 모두 몇 장의 이미지가 있는지 볼 수 있습니다.
  • 상단 도구 모음 — 표시 비율, 어노테이션 필터 드롭다운, 그리고 편집, 삭제, 가져오기, 내보내기, 속성, 학습, 모델, 로그 등의 버튼이 있습니다.

1.2 프로젝트와 데이터셋

프로젝트 추가: 왼쪽의 「+ 프로젝트 추가」를 클릭하고 이름을 입력한 뒤 확인합니다. 프로젝트는 데이터셋의 컨테이너이며, 모든 데이터셋은 반드시 어떤 프로젝트에 속해야 합니다.

프로젝트 노드를 마우스 오른쪽 버튼으로 클릭합니다:

  • 데이터셋 추가 — 프로젝트 아래에 새 데이터셋을 만듭니다
  • 프로젝트 내보내기 — 프로젝트 전체의 데이터셋과 어노테이션을 지정한 형식으로 내보냅니다
  • 이름 변경 — 프로젝트 이름을 바꿉니다
  • 프로젝트 삭제 — 하위의 데이터셋, 어노테이션, 학습 기록까지 함께 지웁니다

데이터셋 노드를 마우스 오른쪽 버튼으로 클릭하면 개별 데이터셋에 대한 작업을 할 수 있습니다: 가져오기 / 내보내기 / 이동 / 이름 변경 / 삭제.

데이터셋을 더블클릭해야 로드됩니다. 이미지와 어노테이션을 다시 스캔하고 캐시를 재구성한 뒤, 오른쪽에서 볼 수 있습니다. 이미 로드된 것(행에 상태 점이 있음)은 다시 더블클릭해도 중복 스캔하지 않습니다.

1.3 데이터 가져오기

데이터셋을 선택하고 상단의 「가져오기」를 클릭하면 가져오기 대화상자가 뜹니다:

  • 이미지 경로 — 이미지가 있는 폴더
  • 라벨 경로 — 라벨 파일이 있는 폴더
  • 라벨 형식 — Yolo txt / Labelme json / 하위 폴더 기준 분류 가져오기
분류 데이터셋은 「하위 폴더 기준 분류 가져오기」를 선택합니다. 각 하위 폴더 이름이 하나의 클래스가 되며, 라벨 파일이 필요하지 않습니다.
OCR은 Labelme json을 사용합니다. 텍스트 상자의 라벨은 「text」로 고정되며, 가져온 뒤 자동으로 텍스트 검출 데이터셋으로 표시됩니다.

1.4 데이터셋 속성

데이터셋을 선택하고 상단의 「속성」을 클릭하면 이미지 경로, 라벨 경로, 그리고 라벨 분포 막대그래프를 볼 수 있습니다. 각 클래스에 어노테이션 상자가 몇 개 있는지를 보여줍니다. 어느 클래스의 샘플이 적은지 한눈에 알 수 있습니다.

1.5 인터페이스 언어

도구 모음 맨 오른쪽에 인터페이스 언어 드롭다운이 있으며, 아홉 가지 언어 중에서 고를 수 있습니다: 中文, English, 繁體中文, 日本語, 한국어, Deutsch, Español, Français, Tiếng Việt.

선택하면 메인 화면이 곧바로 바뀌고, 이미 열려 있는 로그 및 학습 대기열 창도 함께 새로 고쳐집니다. 아직 열지 않은 대화상자는 다음에 열 때 새 언어로 표시됩니다. 선택한 언어는 기억되어 다음에 실행해도 그대로 유지됩니다. 드롭다운의 각 항목은 해당 언어의 표기로 나열되므로, 현재 인터페이스가 어떤 언어든 어떤 항목을 골라야 하는지 알아볼 수 있습니다.

2. 어노테이션

2.1 어노테이션 화면 열기

데이터셋을 선택한 뒤 썸네일을 마우스 오른쪽 버튼으로 클릭해 「어노테이션」을 선택하거나, 썸네일을 바로 더블클릭합니다.

2.2 상자 그리기

어노테이션 화면 상단 도구 모음에는 세 가지 그리기 방식이 있습니다:

  • 사각형 — 마우스를 끌어 상자를 그립니다
  • 다각형 — 꼭짓점을 차례로 클릭하고, 더블클릭하거나 Enter를 눌러 끝냅니다(세그멘테이션 작업용)
  • 텍스트 — 먼저 상단의 「텍스트 어노테이션」 스위치를 켜고 상자를 그립니다. 마우스를 놓으면 입력 상자가 떠서 문자를 입력하고, 더블클릭으로 수정할 수 있습니다(OCR 작업용)

텍스트 상자는 항상 사각형으로 그립니다. 기울어진 문자도 수평 상자로 덮으면 됩니다. 학습 시 다각형은 수평 외접 상자로 처리되므로, 윤곽을 따라 그려도 추가 이점이 없습니다.

도구 모음에는 「이미지 삭제」도 있어 현재 이미지를 지울 수 있습니다.

클래스는 오른쪽 라벨 목록에서 선택합니다.

「어노테이션 표시」 스위치는 모든 윤곽(상자 선, 라벨, 꼭짓점 핸들)을 언제든 숨겨 원본 이미지를 보기 편하게 해줍니다. 이미 붙여 넣었지만 아직 배치하지 않은 내용은 윤곽만 숨겨지고 패턴은 그대로 표시되므로, 이 스위치를 끄면 「붙였을 때 어떤 결과인지」를 미리보기에 딱 좋습니다.

오른쪽 아래의 「어노테이션 정보」에는 이 이미지의 각 어노테이션 객체의 형태(사각형 / 다각형), 꼭짓점 수, 면적이 나열됩니다. 바로 아래의 이미지 정보는 현재 이미지의 너비 × 높이 × 채널 수(예: 505×505×3)와 번호를 표시합니다.

그 아래는 클립보드입니다. 다각형을 마우스 오른쪽 버튼으로 복사하면 복사한 영역의 썸네일(120 × 90)이 추가되며, 최대 9장까지 세로로 나열되고 스크롤할 수 있습니다. 가장 최근 장은 기본으로 선택되고 파란 테두리가 붙습니다. 썸네일을 마우스 오른쪽 버튼으로 클릭하면 이 장을 삭제하거나 전체를 비울 수 있습니다.

2.3 라벨 관리

어노테이션 화면 오른쪽에 라벨 목록이 있고, 위쪽에 「라벨 추가」가 있습니다:

  • 라벨 이름 — 여러 라벨은 쉼표로 구분하며, 한 번에 여러 개를 추가할 수 있습니다
  • 가져오기 — 다른 데이터셋에서 라벨을 통째로 가져옵니다
  • 색상 선택 — 미리 정의된 색상 팔레트에서 고르거나 「사용자 지정 색상」을 클릭해 직접 고릅니다

2.4 클래스 변경

하나만 변경: 어노테이션 상자를 클릭하면 클래스 드롭다운 메뉴가 뜹니다. 새 클래스를 선택하면 됩니다. 오른쪽 라벨 목록의 라벨도 이름 변경, 색상 변경, 삭제가 가능합니다.

일괄 변경: 썸네일을 마우스 오른쪽 버튼으로 클릭 → 「클래스 일괄 수정」을 선택하고 원래 클래스와 새 클래스를 입력하면, 데이터셋 전체에서 이 클래스의 어노테이션이 모두 이름이 바뀝니다.

2.5 어노테이션 객체 복사·붙여넣기

다각형 어노테이션을 마우스 오른쪽 버튼으로 클릭하면 두 가지 작업이 있습니다:

  • 복사 — 이 영역의 픽셀을 템플릿으로 저장하고, 동시에 오른쪽 아래 클립보드에 썸네일을 생성합니다
  • 채우기 — 영역 안의 픽셀을 「채우기 값」 세 칸에 해당하는 RGB 색상(채널당 0 ~ 255, 기본값 255)으로 바꿉니다. 결함을 배경색으로 지울 때 주로 사용합니다

클립보드의 썸네일 한 장을 왼쪽 버튼으로 클릭한 뒤 마우스를 캔버스로 옮기면 다각형 점선이 따라옵니다. 모양은 회전된 실제 윤곽이며, 이번에 뽑힌 각도가 적용되어 있습니다. 위치와 방향을 먼저 확인하고, Esc를 눌러 점선을 없애 일반 마우스 모드로 돌아간 다음, 마우스 오른쪽 버튼으로 「붙여넣기」를 선택해 배치합니다.

이미지의 빈 곳을 마우스 오른쪽 버튼으로 클릭해 「붙여넣기」를 선택하면, 클립보드에서 현재 선택된 장을 마우스 위치에 붙여 넣습니다. 같은 이미지든 다른 이미지든 상관없습니다. 붙여 넣기 전에 도구 모음에서 다음 항목들을 먼저 설정합니다:

  • 각도 범위 — 붙여 넣을 때 무작위로 회전하는 각도 구간(기본값 -180 ~ 180)입니다. 점선 미리보기에도 이 구간에서 뽑힌 각도가 사용되어, 보이는 그대로 적용됩니다
  • 블렌드 강도 — 0 ~ 1, 기본값 0.70. 붙여 넣을 때 밝기 보정과 가장자리 페더링을 자동으로 적용해, 붙인 부분이 배경과 자연스럽게 이어지게 합니다. 0으로 설정하면 그대로 딱 붙습니다
  • 채우기 값 — R / G / B 세 개의 입력 칸(채널당 0 ~ 255, 기본값 255)이며, 마우스 오른쪽 버튼의 「채우기」와 함께 사용해 영역을 이 색으로 지웁니다
  • Ctrl + Z — 가장 최근의 붙여 넣기 또는 채우기를 취소합니다. 픽셀이 복원되고 그에 따라 추가된 어노테이션도 함께 제거되며, 연속해서 취소할 수 있습니다

2.6 다각형 영역 밝기 조절

다각형을 클릭해 선택한 뒤 도구 모음의 「설정」에서 밝기를 켜면, 이 다각형 안 픽셀의 밝기를 바꿀 수 있습니다. 슬라이더를 끌거나 값을 직접 입력하면 이미지에서 실시간으로 미리 볼 수 있습니다.

  • 범위 — 0 ~ 1이며, 기본값 0.50은 원본 그대로를 뜻합니다. 1에 가까울수록 밝아지고(1.00은 약 두 배 밝기), 0에 가까울수록 어두워집니다(0은 완전 검정)
  • 선택된 다각형에만 적용됩니다. 사각형이거나 아무것도 선택하지 않았을 때는 안내만 표시하고 픽셀은 건드리지 않습니다. 다른 다각형을 클릭하면 슬라이더가 그 다각형의 값(조절한 적이 없으면 모두 0.50)으로 돌아가며, 이전 것의 밝기가 넘어오지 않습니다
  • 언제 저장되는가 — 끄는 동안에는 메모리만 바뀌고 실시간으로 미리 보여줍니다. A / D로 이미지를 넘기거나 Ctrl + S를 눌러야 이미지 파일에 기록됩니다
  • 취소 — 한 번의 조절은 한 단계로만 기록되며, Ctrl + Z로 조절 전으로 돌아갑니다. 같은 조절 안에서 왔다 갔다 여러 번 끌어도 한 단계로만 셉니다

2.7 클래스별로 이미지 필터링

상단 도구 모음의 클래스 드롭다운에서 특정 클래스를 선택하면, 이미지 영역에 해당 클래스가 포함된 이미지만 표시됩니다. 특정 클래스를 집중적으로 확인하거나 어노테이션을 보완할 때 편리합니다.

3. 학습

3.1 학습 파라미터 설정

홈 화면 또는 모델 화면의 「학습」을 클릭하면 파라미터 설정 창이 뜹니다:

  • 작업 유형 — 객체 검출 / 세그멘테이션 / 분류 / 이상 검출 / OCR이며, 데이터셋 형식에 따라 자동으로 바뀝니다
  • 학습 세트 / 검증 세트 — 여러 개를 선택할 수 있고, 프로젝트를 넘나들며 조합할 수도 있습니다
  • 장치 — 사용 가능한 GPU를 자동으로 나열합니다
  • 에포크 / 옵티마이저 / 조기 중단 — 옵티마이저는 객체 검출과 세그멘테이션에 adamw, 분류에 sgd를 사용합니다. 조기 중단은 연속 N 에포크 동안 향상이 없으면 미리 끝내는 것이며, 0을 입력하면 끕니다
  • 학습률 — 학습 과정에서 자동으로 감쇠합니다
  • 배치 / 이미지 크기 / 그래디언트 누적 / 스레드 수 — 이미지 크기는 반드시 32의 배수여야 합니다. VRAM이 부족하면 배치를 줄이고 그래디언트 누적을 늘리면, 배치를 키운 것과 같은 효과입니다
  • 출력 경로 — 비워 두면 시간 기준으로 디렉터리를 자동 생성하며, 「찾아보기」를 클릭해 지정할 수도 있습니다

3.2 학습 대기열

파라미터를 설정한 뒤 「학습 시작」 외에도 「대기열에 추가」를 클릭해 작업을 먼저 걸어 두고 다음 작업을 설정할 수 있습니다. 홈 화면에서 「학습 대기열」을 클릭해 대기열 창을 엽니다:

  • 대기열은 순서대로 실행되며, 객체 검출 / 세그멘테이션 / 분류 / 이상 검출 / OCR을 섞어 놓을 수 있고, 한 항목이 끝나면 자동으로 다음 항목으로 넘어갑니다
  • 위로 / 아래로 / 제거 — 실행 순서를 조정하거나 작업을 삭제합니다
  • 편집 — 선택한 작업의 파라미터를 수정합니다
  • 종료된 항목 정리 — 이미 끝난 기록을 빼냅니다
  • 대기열 시작 — 대기열의 작업을 처음부터 차례대로 실행합니다
대기열은 밤새 돌리기에 적합합니다. 여러 데이터셋의 작업을 한 번에 설정해 두면, 소프트웨어가 자동으로 전부 끝내고 각각 모델을 저장합니다.

3.3 학습 진행 상황

「학습 시작」을 클릭하면 홈 화면으로 돌아가고, 상단에 진행률 표시줄과 제어 표시줄이 나타납니다:

  • 작업 이름 + 진행률 — coco128 학습 중 5/100과 같은 형태이며, 진행률 표시줄 안에 현재 에포크의 loss가 표시됩니다
  • 학습 중지 — 언제든 중단할 수 있으며, 이미 끝난 부분은 저장됩니다
  • 남은 시간 — 이미 사용한 시간을 바탕으로 외삽해 추정합니다
  • VRAM — GPU VRAM 점유율로, 실시간으로 갱신됩니다

3.4 학습 곡선

모델 관리에서 학습 기록 하나를 선택하고, 오른쪽 상세 패널의 「전체 지표 보기」를 클릭하면 학습 곡선 창이 뜹니다:

  • 위쪽 절반은 val loss 곡선입니다
  • 아래쪽 절반은 mAP@50-95 / mAP@50 / AR / F1 / precision / recall 등 여러 곡선이며, 세그멘테이션 작업은 mask mAP가 한 줄 더 있습니다
  • 오른쪽 위의 「라벨 필터」 드롭다운으로 전체 지표 또는 특정 클래스의 곡선으로 전환해 볼 수 있습니다

4. 모델 관리

홈 화면의 「모델」을 클릭하면 모델 관리가 열립니다. 왼쪽은 학습 기록 목록, 오른쪽은 상세 패널입니다.

4.1 목록과 필터

  • 검색창 — 프로젝트 / 데이터셋 / 라벨 키워드로 필터링합니다
  • 작업 / 상태 드롭다운 — 작업은 객체 검출 / 세그멘테이션 / 분류 / 이상 검출 / 텍스트 검출 / 텍스트 인식 중에서 고를 수 있습니다. 상태는 학습 중 / 완료 / 실패 / 중지됨 중에서 고를 수 있습니다
  • 데이터셋별 최고 성능만 보기 — 같은 데이터셋에서는 정확도가 가장 높은 항목만 남깁니다
  • 목록 열: 작업, 데이터셋·라벨, 정확도, 학습 시각, 소요 시간, 이미지 크기, 작업
  • 정확도 열에는 색 막대가 있음 — 초록 ≥ 0.8, 노랑 0.5 ~ 0.8, 빨강 < 0.5. 실패 또는 중지됨 기록은 이 열에 상태 텍스트가 표시되며, 마우스를 올리면 실패 원인을 볼 수 있습니다
  • 행 안의 세 버튼: 테스트(모델 테스트 열기), 내보내기, 삭제(해당 학습 기록도 함께 지움)

4.2 상세 패널

아무 행이나 클릭하면 오른쪽에 해당 기록의 전체 파라미터가 표시됩니다: 작업·스케일, 상태, 정확도, 학습 / 검증 세트, 이미지 크기, 에포크 수 / 조기 중단, 배치 크기, 학습률, 옵티마이저, 장치, 라벨, 학습 시각, 소요 시간, 모델 경로. 위쪽에는 정확도 곡선의 썸네일도 있습니다.

패널 아래쪽에 네 개의 버튼이 있습니다:

  • 전체 지표 보기 — 학습 곡선 창을 엽니다(「학습 곡선」 절 참조)
  • 이 모델 테스트 — 이 모델로 테스트 대화상자를 엽니다(「테스트 파라미터」 절 참조)
  • 이 구성으로 재학습 — 이 기록의 모든 학습 파라미터를 그대로 불러와 학습을 다시 시작합니다
  • 모델 디렉터리 열기 — 파일 탐색기에서 가중치 파일 위치를 엽니다

4.3 ONNX 내보내기

「내보내기」를 클릭하고 디렉터리를 선택하면 「项目_时间戳」 폴더가 생성됩니다:

  • 모델 .onnx — 객체 검출과 세그멘테이션은 RF-DETR이 내보내고, 분류와 OCR은 torch가 내보냅니다. 이름은 「项目_任务_图像尺寸_模型规模.onnx」입니다
  • classes.txt — 클래스 id와 이름의 대응표입니다. OCR의 인식 단계는 vocab.txt이며, 한 줄에 한 문자씩이 곧 어휘입니다
  • 모델 평가 보고서 PDF — 검증 세트에서 자동으로 평가를 한 번 돌리고, 테스트 보고서 템플릿을 재사용하며, 이름은 「…_评估报告.pdf」입니다
  • examples/ — C++ / C# / Python으로 ONNX를 호출해 객체 검출, 세그멘테이션, 분류를 하는 예제 코드입니다. OCR은 현재 Python 버전만 있습니다

내보내기 과정에는 진행 안내가 표시됩니다. ONNX 변환에는 onnx와 onnxsim이 설치되어 있어야 하며, 설치되어 있지 않으면 팝업으로 안내합니다.

분류 작업은 평가 보고서를 생성하지 않습니다. 미검출·오검출 방식의 보고서는 분류에 적용되지 않기 때문입니다. OCR의 텍스트 인식도 마찬가지로, 결론은 CER 하나뿐입니다.

5. 테스트와 평가 보고서

5.1 테스트 파라미터

모델 관리에서 행 안의 「테스트」(또는 상세 패널의 「이 모델 테스트」)를 클릭하면 테스트 대화상자가 뜹니다. 위쪽에 모델 정보가 표시됩니다: 작업 유형, 가중치 파일, 학습 정확도, 입력 크기, 스케일. 아래는 파라미터입니다:

  • 데이터 — 프로젝트를 넘나들며 모든 데이터셋을 선택할 수 있습니다
  • 장치 — 기본값은 첫 번째 사용 가능한 GPU입니다
  • 신뢰도 — 이 점수보다 낮은 예측은 그냥 버립니다
  • IoU 임계값 — 예측 상자와 어노테이션 상자의 겹침 정도가 기준을 넘어야 정상 검출로 인정합니다
  • 라벨 파일 출력 — 체크하면 예측 상자를 labelme json으로 작성해 사람이 검토하기 편합니다
  • OCR — 텍스트 검출은 추론과 평가 두 갈래로 나뉩니다. 추론은 결과를 어노테이션 json으로 작성하고, 평가는 P/R을 집계합니다. 텍스트 인식은 어노테이션 파일을 출력하지 않고, 문자 조각의 인식률만 보고합니다
데이터셋에 어노테이션이 있으면 자동으로 평가 모드로 들어가 재현율 / 미검출 / 오검출을 집계합니다. 텍스트 검출에서 추론 모드를 선택하면 어노테이션을 무시하고 예측 상자를 바로 json으로 작성합니다.

5.2 결과 분석

테스트가 끝나면 결과 분석 창이 뜹니다. 두 가지 기준으로 집계하며, 표현은 모두 직관적인 「정상 검출 / 미검출 / 오검출」입니다:

  • 이미지 기준(장 단위 집계, 1개만 검출해도 검출로 인정) — 테스트 장 수, 검출 이미지 및 재현율, 미검출 이미지, 오검출이 있는 이미지
  • 어노테이션 기준(어노테이션 상자 단위 집계) — 정상 검출, 미검출, 오검출, 정확도
  • 클래스별 표 — 각 클래스의 어노테이션 수, 정상 검출, 미검출, 오검출, 재현율, 정확도
  • 텍스트 인식 — 상자 단위로 집계하지 않고, 문자 조각 총수, CER(문자 오류율) 및 전부 맞은 조각 수를 보고합니다
  • 아래쪽 결론 — 전체가 미검출 쪽인지 오검출 쪽인지, 그리고 가장 발목을 잡는 클래스가 무엇인지 한 문장으로 짚어 줍니다

5.3 PDF 보고서 내보내기

오른쪽 아래의 「PDF 보고서 내보내기」를 클릭하면 백그라운드 스레드에서 생성되며, 내용은 다음과 같습니다:

  • 개요 페이지 — 지표 요약 표 + 어노테이션 분포도
  • 미검출 샘플 페이지 / 오검출 샘플 페이지 — 「클래스별 N장 추출」 방식으로 썸네일을 보여주고(수량은 왼쪽 아래에서 조정), 이미지 위에 빨간 상자로 미검출과 오검출 위치를 표시하며, 추출 비율도 명시합니다
  • 제안 페이지 — 각종 오류에 대한 개선 방향을 제시합니다
샘플링은 보고서를 만드는 이 단계에서만 일어나며, 상세 데이터는 여전히 전체이므로 이후 어려운 사례 발굴을 해도 데이터가 유실되지 않습니다.

6. OCR

OCR은 다른 작업과 다릅니다. 두 개의 모델을 이어 붙여 완성합니다. 텍스트 검출이 문자 상자를 찾아내고, 텍스트 인식이 상자 안의 문자를 읽습니다. 학습, 테스트, 내보내기가 모두 두 단계로 나누어 진행되며, 모델 관리에 두 개의 기록이 남습니다.

6.1 텍스트 어노테이션

어노테이션 화면에서 상단의 「텍스트 어노테이션」 스위치를 켜면, 클래스가 자동으로 예약 라벨 「text」로 고정됩니다(라벨을 먼저 만들 필요가 없습니다). 사각형을 그리듯 문자를 감싸고 마우스를 놓으면 입력 상자가 떠서 내용을 입력하며, 이미 있는 텍스트 상자는 더블클릭하면 언제든 수정할 수 있습니다.

텍스트 상자는 항상 사각형으로 그립니다. 기울어진 문자도 수평 상자로 덮으면 되고, 학습 시 다각형은 수평 외접 상자로 처리되므로 윤곽을 따라 그려도 추가 이점이 없습니다.

텍스트 상자가 있는 labelme json을 가져오면 데이터셋이 자동으로 텍스트 검출 데이터셋으로 표시됩니다. 이후에는 이런 데이터셋만 OCR의 학습 세트 드롭다운에 나타납니다.

어노테이션을 마치고 데이터셋 보기로 돌아오면, OCR 데이터셋에서는 각 텍스트 상자가 개별 썸네일로 잘려 표시되고, 라벨 바에는 클래스 이름이 아니라 상자에 입력한 문자 내용이 표시됩니다(3개를 넘으면 +N으로 접힘). 한 장씩 넘겨 보면 내용을 제대로 입력했는지 확인할 수 있습니다. 위쪽 클래스 필터에는 「text」 항목 하나만 있습니다.

6.2 학습

작업 유형에서 OCR을 선택합니다.

이미지 크기는 문자 인식 학습에 사용되지 않습니다(인식 단계는 32×768로 고정되며, 입력란은 비활성화되고 768로 표시됩니다).

「학습 시작」을 클릭하면 자동으로 두 항목으로 나뉘어 대기열에 들어갑니다. 먼저 텍스트 검출, 다음으로 텍스트 인식입니다. 앞 항목이 끝나면 VRAM이 학습 시작 전 수준으로 내려갈 때까지 기다렸다가 다음 항목을 시작합니다. 이 동안 진행 영역에는 「VRAM 해제 대기 · 다음: 텍스트 인식」이 표시되어 중간에 비는 시간이 없습니다.

인식 단계의 어휘는 어노테이션에 등장한 문자를 그대로 가져옵니다. 따라서 어노테이션 텍스트는 현장에서 실제로 마주칠 문자 집합을 모두 담아야 합니다. 현장에는 있지만 어노테이션에 등장하지 않은 문자는 모델이 알아보지 못합니다.

6.3 테스트: 검출은 두 갈래, 인식은 한 갈래

  • 텍스트 검출 · 추론 — 어노테이션과 대조하지 않고, 예측 상자(인식된 문자 포함)를 바로 labelme json으로 작성합니다. 작성된 json에는 OCR 표시가 있어 소프트웨어로 다시 끌어오면 텍스트 검출 데이터셋으로 인식되며, 결과를 확인하거나 어노테이션을 보완하는 데 쓸 수 있습니다
  • 텍스트 검출 · 평가 — 데이터셋에 어노테이션이 있으면 자동으로 들어가며, 정상 검출 / 미검출 / 오검출과 클래스별 P/R을 집계합니다. 객체 검출 작업과 동일합니다
  • 텍스트 인식 — 어노테이션 상자에서 잘라낸 문자 조각으로 테스트하며, 문자 조각 총수, CER(문자 오류율) 및 전부 맞은 조각 수를 보고하고 어노테이션 파일은 출력하지 않습니다

6.4 내보내기

두 단계에서 각각 ONNX 하나씩 내보냅니다: 项目_字符检测_尺寸_规模.onnx와 项目_字符识别_尺寸_规模.onnx. 인식 단계에는 vocab.txt 어휘가 하나 더 붙습니다.

텍스트 검출은 평소대로 평가 보고서를 생성합니다. 텍스트 인식은 CER이라는 결론 하나뿐이라 보고서를 생성하지 않습니다.

호출 예제는 내보낸 디렉터리의 examples/python/ocr.py에 있습니다. 검출 단계 출력 logits에는 sigmoid가 적용되지 않으므로 후처리를 직접 작성해야 하며, 예제에 모두 작성되어 있습니다.

7. 로그

홈 화면 상단의 「로그」를 클릭하면 로그 창이 열리고, 실시간으로 스크롤되며 표시됩니다:

  • 소프트웨어 시작 / 종료
  • 프로젝트와 데이터셋의 생성, 이름 바꾸기, 삭제, 가져오기 / 내보내기
  • 라벨의 생성, 이름 바꾸기, 삭제
  • 학습의 시작, 진행 중([train] 접두사로 하위 프로세스 출력 전달), 지표 갱신, 모델 저장, 수동 중지
  • 테스트의 시작, 진행 중([test] 접두사), 완료, 실패
