# Easy Trainer

基于 PySide6 的本地图像标注与深度学习训练工具，支持**目标检测 / 图像分割 / 图像分类**三类任务的标注、训练、测试与模型管理全流程。数据存储于本地 LMDB，无需联网即可完成标注 → 训练 → 评估闭环。

## 功能特性

- **项目管理**：多项目 / 多数据集管理，支持创建、导入、移动、重命名、删除
- **图像标注**
  - 目标检测：矩形框标注，labelme JSON / YOLO txt 格式导入导出
  - 图像分割：多边形标注（labelme JSON 格式）
  - 图像分类：按子文件夹导入（子文件夹名 = 类别），点击类别名即可快速改类
- **数据导入**：单图或批量导入，支持分类根目录 / 标签目录自动匹配、进度显示、懒加载缩略图（大数据集秒级载入）
- **模型训练**（子进程执行，不阻塞界面）
  - 目标检测 / 分割：RF-DETR（nano / small / medium / large）
  - 图像分类：ResNet（18 / 34 / 50 / 101，网络下拉映射）
  - 实时进度条、损失 / 精度曲线、预计剩余时间、显存占用、手动停止
- **测试 / 评估**
  - 检测 / 分割：P / R / mAP 评估，测试结果表格（检出率、准确率、漏检、误检）
  - 分类：每类正确 / 错误统计，整体精度与最差类别定位
- **模型管理**：训练历史列表（精度列），支持指标折线图回看、模型测试与删除
- **在线日志**：训练 / 测试 / 操作日志实时输出，异常自动弹出

## 环境要求

| 依赖 | 版本 | 说明 |
|------|------|------|
| Python | ≥ 3.10 | RF-DETR 要求 Python 3.10+ |
| PySide6 | ≥ 6.6 | GUI 框架 |
| lmdb | ≥ 1.4 | 本地数据存储 |
| Pillow | ≥ 9.0 | 图像处理 |
| matplotlib | ≥ 3.5 | 指标曲线绘制 |
| numpy | ≥ 1.21 | 数值计算 |

**训练 / 推理额外依赖**（需在 Python 3.10+ 环境安装）：

```bash
pip install torch torchvision
pip install rfdetr>=1.9.2
```

## 快速开始

```bash
# 1. 安装基础依赖
pip install -r requirements.txt

# 2. 安装训练依赖（Python 3.10+）
pip install torch torchvision "rfdetr>=1.9.2"

# 3. 启动
python app/main.py
```

## 使用流程

1. **新建项目** → 在项目下添加数据集
2. **导入数据**：右键数据集 → 导入。检测/分割选图像目录 + 标签目录（labelme/yolo），分类勾选"按子文件夹分类导入"（子文件夹名即类别）
3. **标注**：双击数据集图像进入标注界面。分类数据集中间显示类别名，点击可切换类别（自动移动到对应子文件夹）
4. **训练**：工具栏"训练" → 选任务类型（检测/分割/分类）→ 配置参数 → 开始训练（5 秒倒计时后进入后台执行）
5. **测试**：模型管理 → 某条记录"测试" → 配置 → 运行评估（检测输出 labelme 标签文件，分类弹结果表格）
6. **回看指标**：模型管理 → "指标"打开精度曲线

> 提示：分割训练图像尺寸需为 12 的倍数（默认 636）；检测默认 640；分类默认 224。图像尺寸输入框悬停可见推荐值。

## 数据存储

- **应用数据**：`~/.easy_trainer/app.mdb`（LMDB，保存项目/数据集绑定、标签、训练历史、删除记录等）
- **训练输出**：各任务 `输出路径` 下的时间戳目录（config.json / result.json / metrics.json / checkpoint）
- **运行日志**：`logs/app.log`（滚动按天归档）
